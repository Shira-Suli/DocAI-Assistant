The system is designed to answer user questions in the context of the entire document, not just isolated lines.

When a user highlights a specific section, it is treated as a focal point, while the AI still considers the broader document context to ensure accurate and meaningful answers.

The backend preprocesses the document, selects relevant sections, and constructs a controlled prompt before sending it to the AI model.

This approach ensures contextual understanding, prevents out-of-context answers, and demonstrates meaningful AI integration beyond simple question–answer interaction.
